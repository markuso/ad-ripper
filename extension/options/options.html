    JavaScript injection

    Chrome only runs extension-provided scripts once you allow it:

    1. Open chrome://extensions.
    2. Chrome 138+: click Details on Ad Ripper and turn on Allow User Scripts.
      Chrome 120–137: turn on Developer mode (top-right).
    3. Come back here and click Re-check.

    Rule reference

    Scopes

    All sites
    Every page.
    Domain
    example.com matches example.com and every subdomain (www.example.com, news.example.com…). For network rules this means requests made by pages on that domain.
    URL pattern
    Matched against the full page URL. * is a wildcard, e.g. https://example.com/news/*. A pattern without * matches any URL that starts with it. Not available for network rules.

    Network filter syntax

    ads.example.com
    A bare domain blocks that domain and its subdomains.
    ||example.com/ads/*
    Chrome urlFilter syntax: || anchors a domain, | anchors start/end, ^ is a separator, * is a wildcard.
    /banner\d+\.gif/
    Text wrapped in slashes is a regular expression.
